# Jay | Software Developer Portfolio

A modern, responsive, and interactive 3D developer portfolio showcasing full-stack projects, applied technical skills, and software engineering experience.

## Tech Stack

- **Frontend:** React.js, Tailwind CSS
- **3D Graphics & Animations:** Three.js, @react-three/fiber, @react-three/drei, Framer Motion
- **Build Tool:** Vite

## Key Features

- **Interactive 3D Tech Stack:** Floating 3D spheres powered by Three.js displaying core technologies and developer tools with hover tooltips.
- **Dynamic Project Showcase:** Expandable project cards with links to live demos and GitHub repositories.
- **Responsive & Modern Design:** Tailored color palette, sleek typography, and mobile-friendly layouts.
- **Performant Scroll Animations:** Smooth viewport-triggered animations optimized for quick navigation.

## Getting Started

### Prerequisites

- Node.js (version 16.0.0 or higher)
- npm (version 9.0.0 or higher)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/jayzba/Personal-Website.git
   ```

2. Navigate into the directory and install dependencies:
   ```bash
   cd Personal-Website
   npm install
   ```

3. Start the local development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
